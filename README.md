# 跳跃冒险 (Jump Adventure)

一款使用 HTML5 Canvas 和原生 JavaScript 开发的 2D 平台跳跃游戏。

**在线游玩：** [https://manxisuo.github.io/jump-adventure/](https://manxisuo.github.io/jump-adventure/)

## 游戏特色

- 🎮 流畅的操控手感（加速/摩擦、土狼时间、跳跃缓冲、可变跳跃高度）
- 🦘 二段跳能力
- 🚀 水平/垂直移动平台
- 💰 金币收集系统
- ⚠️ 多种危险物（尖刺、岩浆、移动敌人）
- 🚩 检查点存档系统
- 🏁 关卡完成统计（金币、时间、死亡次数）
- 🎯 三种难度选择
- 📱 自适应屏幕大小
- 🎨 精美的像素风格画面

## 操作说明

| 操作 | 按键 |
|------|------|
| 移动 | ← → 方向键 或 A D |
| 跳跃 | ↑ 方向键 或 W 或 空格键 |
| 二段跳 | 在空中再次按跳跃键 |
| 选择难度 | ↑ ↓ 方向键 |
| 开始游戏 | Enter 或 空格键 |
| 重新开始 | R |

## 难度说明

- **简单模式**：5 条生命，较慢的机关速度
- **普通模式**：3 条生命，标准难度
- **困难模式**：1 条生命，更快的机关速度

## 游戏目标

1. 收集沿途的金币
2. 避开尖刺、岩浆和敌人
3. 触碰检查点旗帜保存进度
4. 到达金色终点旗帜完成关卡

## 技术实现

- 纯 HTML5 Canvas 渲染
- 原生 JavaScript，无外部依赖
- 响应式画布缩放
- 平滑的相机跟随系统
- 物理引擎（重力、加速度、碰撞检测）

## 本地运行

1. 克隆仓库
2. 在浏览器中打开 `index.html`

无需任何构建步骤或服务器。
